Acerca de este proyecto

Este proyecto corresponde a una aplicación web de gestión de tareas (To-Do List) desarrollada con HTML, CSS y JavaScript puro, sin utilizar frameworks externos.

El objetivo fue practicar la manipulación del DOM, la gestión de eventos y el almacenamiento local mediante localStorage, permitiendo que las tareas permanezcan guardadas incluso después de recargar la página.

Entre las principales funcionalidades implementadas se encuentran la creación de tareas, su eliminación, el cambio de estado entre pendientes y completadas, además de filtros para visualizar las tareas según su estado.

Este proyecto forma parte del portafolio XIX y representa una práctica enfocada en el desarrollo frontend y la construcción de aplicaciones web interactivas utilizando JavaScript.
